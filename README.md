## 🚀 Cómo usar este repositorio

### Clonar el repositorio

```bash
git clone https://github.com/Bruno1906-bg/Practica-phyton.git
cd Practica-phyton
```

### Ejecutar ejercicios en Python

```bash
cd PracticaPY
python nombre_del_archivo.py
```

### Ejecutar ejercicios en JavaScript

```bash
cd PracticaJS
node nombre_del_archivo.js
```
